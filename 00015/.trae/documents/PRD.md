## 1. 产品概述

"记忆中的玻璃球"是一个基于Three.js的交互式3D网页应用，用户输入年份和颜色后，场景中央生成一个半透明玻璃球，球内漂浮着与该年代相关的怀旧物品小图标，点击可查看虚构的怀旧文案，唤起对往昔时光的情感共鸣。
- 目标用户：怀旧情感爱好者、创意内容创作者、社交分享用户
- 核心价值：通过3D视觉与交互体验，让用户以沉浸式方式"触碰"记忆，并将独特的玻璃球场景分享给他人

## 2. 核心功能

### 2.1 用户角色
无角色区分，所有用户享有相同功能。

### 2.2 功能模块
1. **主场景页**：3D玻璃球场景、年份/颜色输入面板、物品交互、截图分享、自定义物品添加、配置保存

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主场景页 | 输入面板 | 年份输入（1900-2030）、颜色选择器，点击"生成"创建玻璃球 |
| 主场景页 | 3D玻璃球 | 半透明球体，内部漂浮年代物品，球体颜色由用户选择决定，球体可旋转/缩放 |
| 主场景页 | 物品漂浮系统 | 根据年份从本地映射表匹配物品，物品在球内缓慢漂浮旋转 |
| 主场景页 | 物品点击交互 | 点击物品弹出悬浮卡片，展示虚构怀旧文案和物品名称 |
| 主场景页 | 截图分享 | 将当前3D场景截图并下载为PNG图片 |
| 主场景页 | 自定义物品添加 | 输入物品名称和描述，生成简易3D模型占位符添加到球内 |
| 主场景页 | 配置保存 | 将当前玻璃球的年份、颜色、物品列表保存为JSON文件下载 |

## 3. 核心流程

用户打开页面 → 输入年份和选择颜色 → 点击生成 → 玻璃球动画出现 → 球内漂浮年代物品 → 用户可旋转/缩放查看 → 点击物品查看文案 → 可添加自定义物品 → 可截图分享或保存配置JSON

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深邃夜空蓝(#0a0e27)为背景，用户选择的颜色作为玻璃球主色
- 辅助色：暖金色(#c9a96e)用于文字高亮和边框装饰
- 按钮风格：圆角玻璃拟态按钮，带有微光边框
- 字体：标题使用 ZCOOL QingKe HuangYou（站酷庆科黄油体），正文使用 Noto Sans SC
- 布局：全屏3D场景为主，左侧浮动半透明控制面板
- 图标风格：简约线条图标，带有柔和发光效果
- 整体氛围：梦幻、怀旧、温暖，像在深夜翻阅一本泛黄的相册

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主场景页 | 3D场景区域 | 全屏Three.js画布，深色渐变背景，环境粒子效果 |
| 主场景页 | 控制面板 | 左侧浮动毛玻璃面板，年份输入框、颜色选择器、生成按钮、截图按钮、保存按钮 |
| 主场景页 | 物品文案弹窗 | 居中半透明卡片，物品名称、年代标签、虚构文案，淡入淡出动画 |
| 主场景页 | 自定义物品弹窗 | 居中毛玻璃弹窗，物品名称输入、描述文本域、确认按钮 |

### 4.3 响应式
- 桌面优先设计，全屏3D场景
- 移动端：控制面板改为底部抽屉式面板，触控优化旋转/缩放
- 最小支持宽度 375px

### 4.4 3D场景指导
- 环境：深色太空般背景，微弱星点粒子漂浮
- 灯光：柔和环境光 + 点光源从球体内部散发微光 + 顶部方向光产生高光反射
- 相机：透视相机，默认45度俯视角，支持OrbitControls旋转缩放，相机距离约6个单位
- 构图：玻璃球居中，控制面板在左侧不遮挡主体
- 交互：OrbitControls旋转缩放、Raycaster点击拾取物品、物品悬浮动画
- 后处理：Bloom发光效果让玻璃球边缘有柔和光晕、可选Vignette暗角
- 性能：物品数量控制在15个以内，使用简单几何体组合代替高面数模型
