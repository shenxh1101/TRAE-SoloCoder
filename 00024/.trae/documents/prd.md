## 1. 产品概述

基于 Three.js 的3D太空飞船躲避陨石小游戏。玩家以第三人称视角观察飞船，陨石从远处飞来，飞船固定在场景中央偏下位置。玩家通过鼠标拖拽旋转视角，核心玩法为躲避陨石、积累分数，难度随分数递增。

- 目标用户：休闲游戏玩家、3D视觉体验爱好者
- 核心价值：沉浸式太空飞行体验 + 简单上手的操作方式

## 2. 核心功能

### 2.1 功能模块

1. **游戏主页面**：3D太空场景、飞船、陨石、星空背景、HUD界面

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 游戏主页面 | 3D场景 | 渲染Three.js太空场景，包含飞船模型、陨石、星空粒子系统 |
| 游戏主页面 | 飞船模型 | 立方体机身 + 圆锥体机头 + 扁平长方体机翼，固定在场景中央偏下位置 |
| 游戏主页面 | 陨石系统 | 随机大小的球体/多面体从远处飞向飞船，带自转效果 |
| 游戏主页面 | 碰撞检测 | 陨石碰到飞船时飞船闪烁，生命值减1 |
| 游戏主页面 | HUD界面 | 显示生命值（3条命）、当前得分 |
| 游戏主页面 | 难度递增 | 得分越高，陨石生成速度和数量增加 |
| 游戏主页面 | 游戏结束 | 生命值为0时显示游戏结束画面和重新开始按钮 |
| 游戏主页面 | 截图功能 | 一键截图保存当前画面 |
| 游戏主页面 | 星空背景 | 粒子系统渲染背景星空 |

## 3. 核心流程

1. 用户打开页面，3D太空场景加载完成
2. 陨石从远处持续飞向飞船
3. 飞船固定不动，玩家通过鼠标拖拽旋转视角观察
4. 陨石飞过飞船未碰撞 → 得10分
5. 陨石碰撞飞船 → 飞船闪烁 + 生命值减1
6. 难度随分数递增：陨石生成速度加快、数量增多
7. 生命值为0 → 游戏结束，显示最终得分和重新开始按钮
8. 点击重新开始 → 重置游戏状态

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深空黑 (#0a0a1a) + 星际蓝 (#1a1a4e) + 警告红 (#ff3344)
- **辅助色**：霓虹青 (#00ffcc)、能量橙 (#ff8800)
- **字体**：Orbitron（科幻风格显示字体）+ Exo 2（UI文字字体）
- **按钮风格**：圆角、发光边框、霓虹效果
- **布局**：全屏3D场景 + 浮动HUD覆盖层
- **图标风格**：线条图标，发光效果

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 游戏主页面 | HUD顶部栏 | 生命值心形图标（3颗）、得分数字（霓虹风格）、截图按钮 |
| 游戏主页面 | 3D场景 | 深空背景、飞船模型（金属质感）、陨石（岩石纹理）、星空粒子 |
| 游戏主页面 | 游戏结束弹窗 | 半透明遮罩、居中弹窗卡片、最终得分、重新开始按钮 |
| 游戏主页面 | 碰撞反馈 | 飞船白色闪烁、屏幕边缘红色闪光 |

### 4.3 响应式设计

- 桌面端优先，全屏3D场景
- 移动端自适应Canvas尺寸
- HUD元素使用绝对定位，适配不同屏幕

### 4.4 3D场景指引

- **环境**：深空场景，无环境光贴图，使用程序化星空
- **灯光**：环境光（弱蓝调）+ 方向光（主光源）+ 点光源（飞船引擎光）
- **相机**：透视相机，鼠标拖拽旋转，OrbitControls
- **构图**：飞船居中偏下，陨石从z轴远处飞来
- **交互**：鼠标拖拽旋转视角，鼠标滚轮缩放
- **后处理**：可选bloom效果增强霓虹感
- **性能预算**：陨石池复用，粒子数量控制在2000以内

## 5. 难度递增机制

| 得分区间 | 陨石生成间隔(ms) | 每次生成数量 | 陨石飞行速度 |
|----------|------------------|-------------|-------------|
| 0-100 | 1500 | 1 | 基础 |
| 100-300 | 1200 | 1-2 | +20% |
| 300-600 | 900 | 2-3 | +40% |
| 600-1000 | 700 | 2-3 | +60% |
| 1000+ | 500 | 3-4 | +80% |
