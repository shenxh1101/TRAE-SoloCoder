# 会员积分与优惠券管理系统

一个功能完整的会员积分与优惠券管理系统后端API，支持积分计算、礼品兑换、定向优惠券、自动核销、积分过期管理和报表导出。

## 功能特性

### 1. 积分管理
- ✅ 用户消费时根据会员等级自动计算积分（普通1倍、银卡1.2倍、金卡1.5倍）
- ✅ 生成积分变动记录
- ✅ 积分过期提醒（12月1日起）
- ✅ 自动扣除过期积分（每年1月1日）

### 2. 礼品兑换
- ✅ 积分兑换礼品
- ✅ 库存自动校验
- ✅ 库存不足时推荐替代礼品
- ✅ 兑换记录管理

### 3. 优惠券系统
- ✅ 基于用户行为定向发券（30天未登录、高活跃度）
- ✅ 优惠券有效期和使用门槛设置
- ✅ 订单时自动校验适用优惠券
- ✅ 最优方案自动核销（满减/折扣）

### 4. 报表统计
- ✅ 按月份导出积分发放/消耗统计
- ✅ 优惠券核销率报表
- ✅ 按会员等级和券类型汇总
- ✅ 支持CSV格式导出

## 技术栈

- **运行时**: Node.js
- **框架**: Express.js
- **数据库**: MongoDB
- **定时任务**: node-cron
- **报表导出**: json2csv

## 快速开始

### 安装
```bash
npm install
```

### 配置
复制并编辑 `.env` 文件：
```
PORT=3000
MONGODB_URI=mongodb://localhost:27017/membership_system
```

### 启动
```bash
# 生产模式
npm start

# 开发模式
npm run dev
```

### 测试
```bash
npm test
```

## API文档

详细的API接口文档请查看 [API_DOCUMENTATION.md](./API_DOCUMENTATION.md)

### 主要接口

- **用户管理**: `/api/users`
- **积分管理**: `/api/points`
- **礼品管理**: `/api/gifts`
- **优惠券**: `/api/coupons`
- **订单管理**: `/api/orders`
- **报表导出**: `/api/reports`
