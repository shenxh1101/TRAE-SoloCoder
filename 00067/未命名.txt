## 历史记录机制

- 保存新历史时会截断 `historyIndex` 之后的记录（防止分支历史）
- `undoLayer` 将 `historyIndex` 后退并恢复 `previousState`
- `redoLayer` 将 `historyIndex` 前进并恢复 `nextState`
- 边界情况处理完善（无法撤销/重做时返回 `null`）

已成功创建 `api/server.ts` 和 `api/roomManager.ts`，实现了完整的 WebSocket 实时协作服务器。以下是功能概述：

## `api/roomManager.ts` - 房间状态管理

**核心功能：**
- **房间管理**：`createRoom()` 创建房间，自动维护房间列表，房间为空时自动清理
- **用户管理**：`addUser()` / `removeUser()` 管理用户加入/离开，自动分配颜色，第一个加入的用户为房主，房主离开时自动转移权限
- **消息广播**：`broadcast()` 支持排除发送者广播，`sendToUser()` 发送给指定用户
- **状态同步**：`getCanvasState()` 获取完整状态（图层、活动图层、视图、用户列表）
- **图层状态**：`setLayers()` / `getLayers()` 管理图层数据
- **视图跟随**：`setView()` 更新视图状态，`isHost()` 检查房主权限

**关键代码：**
- `Room` 接口：`id`、`users` (Map)、`layers`、`offset`、`zoom`、`followMode`
- `RoomUser` 接口：扩展 `User`，包含 `ws` WebSocket 连接
- 单例模式导出 `roomManager` 实例

## `api/server.ts` - WebSocket 服务器

**服务器配置：**
- 使用 `http.createServer(app)` 创建 HTTP 服务器，`WebSocketServer` 挂载其上
- 监听 3001 端口，支持 CORS
- 优雅关闭处理（SIGTERM / SIGINT）

**消息处理：**
| 消息类型 | 处理逻辑 |
|---------|---------|
| `user:join` | 添加用户到房间，发送全量状态同步给新用户，广播加入通知给其他人 |
| `user:leave` | 移除用户，广播离开通知 |
| `draw:action` | 广播给房间内其他用户 |
| `layer:create/update/delete/reorder` | 更新服务端图层状态，广播给其他用户 |
| `view:update` | **房主视图变化时更新服务端状态**，广播给其他用户（跟随模式） |
| `cursor:update` | 广播光标位置 |
| `sync:full` | 仅房主可更新服务端状态 |

**边界情况处理：**
- `parseMessage()` 解析失败返回错误
- `try/catch` 包裹消息处理，异常时发送错误消息
- WebSocket `error` 和 `close` 事件触发 `handleDisconnect()`
- `handleDisconnect()` 清理连接映射和房间用户，广播离开通知
- 广播前检查 `ws.readyState === WebSocket.OPEN`

**HTTP API 端点：**
- `GET /api/health` - 健康检查
- `POST /api/rooms` - 创建新房间
- `GET /api/rooms/:roomId` - 获取房间状态
