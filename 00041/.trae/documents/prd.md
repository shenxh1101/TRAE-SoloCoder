## 1. 产品概述

智能家政服务预约与调度系统，面向家庭用户提供一站式家政服务预约、实时跟踪和评价反馈，面向管理员提供服务人员管理、智能调度和数据分析能力。通过历史评分、距离和任务负荷自动推荐最优服务人员，实现从预约到完成的全流程数字化管理。

- 目标用户：有家政服务需求的家庭用户、家政服务人员、平台管理员
- 核心价值：提升预约效率、服务可追溯、评分驱动的质量闭环

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 手机号注册 | 浏览服务、预约下单、实时跟踪、评价打分 |
| 服务人员 | 管理员录入 | 查看任务、扫码签到、更新位置、接收消息 |
| 管理员 | 后台授权 | 人员管理、排班设置、订单查询、报表导出 |

### 2.2 功能模块

1. **首页仪表盘**：待接单数量、服务中订单实时状态、数据10秒自动刷新
2. **服务预约页**：服务类型选择、地址填写、时间选择、特殊要求、智能推荐人员
3. **订单详情页**：二维码生成、签到状态、服务计时、实时位置、消息沟通
4. **评价页**：照片上传、评分打分、文字评价
5. **管理员-人员管理**：技能标签、服务区域、排班规则设置
6. **管理员-订单查询**：多条件组合查询（类型/评价/日期）
7. **管理员-报表导出**：月度质量分析报表、个人服务记录明细

## 3. 核心流程

用户选择服务类型 → 填写地址和时间 → 系统推荐服务人员 → 确认预约生成订单二维码 → 服务人员扫码签到 → 自动开始计时 → 服务中可查看位置和发消息 → 超时15分钟自动提醒补偿 → 服务结束 → 用户评价打分 → 系统调整推荐权重

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：暖橙色（#FF6B35）传达温暖与信赖，辅助色深灰蓝（#2D3748）营造专业感
- 按钮风格：圆角（8px），主按钮实色填充+悬停微阴影，次按钮描边风格
- 字体：标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular
- 布局风格：卡片式布局，左侧固定导航栏，顶部面包屑
- 图标风格：线性图标（lucide-react），统一2px描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页仪表盘 | 统计卡片 | 4列网格卡片，渐变背景色，数字大号加粗，10秒刷新旋转图标 |
| 首页仪表盘 | 实时订单 | 表格布局，状态标签彩色圆角，脉冲动画表示进行中 |
| 服务预约页 | 类型选择 | 3列卡片网格，选中态橙色边框+阴影，图标+文字 |
| 服务预约页 | 人员推荐 | 横向卡片滚动，头像+姓名+评分星+距离+预计到达 |
| 订单详情页 | 二维码 | 居中白色卡片内嵌二维码，下方显示订单号 |
| 订单详情页 | 计时器 | 大号数字时钟，绿色进行中/红色超时 |
| 订单详情页 | 位置地图 | 圆角卡片内地图区域，标记点动画 |
| 评价页 | 评分组件 | 5星交互评分，照片网格上传区 |
| 管理员页面 | 侧边导航 | 固定左侧240px导航栏，图标+文字，当前项橙色高亮 |
| 管理员-报表 | 报表预览 | 图表+数据表格组合，导出按钮固定右上角 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度1280px
- 统计卡片在小屏幕下从4列变2列
- 表格在小屏幕下支持横向滚动
- 管理员侧边栏可折叠为图标模式
