## 1. 产品概述
歌词转诗歌可视化互动平台，将英文歌词转化为三种艺术风格（民谣风、古风、赛博朋克风）的短诗，支持用户评价、单行重生成和批量处理。
- 面向音乐爱好者、诗人、创作者，提供创意文本转换体验
- 通过AI/规则引擎实现风格迁移，支持降级方案确保可用性

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|---------|---------|
| 访客用户 | 无需注册 | 使用所有转换功能、提交评价、批量处理 |

### 2.2 功能模块
1. **主页面**: 歌词输入区、风格转换结果展示、星级评价
2. **单行处理**: 选定特定歌词行，单独生成三种风格变体
3. **批量处理**: 文件上传、批量转换、ZIP下载
4. **评价系统**: 1-5星评价、数据持久化存储

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 主页面 | 歌词输入 | 多行文本输入、示例歌词快速填充 |
| 主页面 | 风格卡片 | 三种风格并排展示、生成动画效果 |
| 主页面 | 星级评价 | 1-5星交互、评价提交反馈 |
| 主页面 | 单行选择 | 点击选中某行歌词、单独重生成 |
| 批量处理 | 文件上传 | TXT文件拖拽上传、预览内容 |
| 批量处理 | 结果下载 | ZIP打包下载、包含所有风格结果 |

## 3. 核心流程
用户输入英文歌词 → 点击生成按钮 → 后端调用转换引擎 → 返回三种风格诗歌 → 前端展示 → 用户可进行星级评价或选择某行单独重生成

```mermaid

    A["用户输入歌词"] --> B["点击生成"]
    B --> C["后端API处理"]
    C --> D["调用转换引擎"]
    D --> E["返回三种风格结果"]
    E --> F["前端展示卡片"]
    F --> G["用户评价/单行重生成"]
    G --> H["评价保存到JSON"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**: 深邃紫 (#6366f1) + 暗夜黑 (#0f172a) + 霓虹青 (#22d3ee)
- **按钮风格**: 圆角渐变按钮、悬浮发光效果
- **字体**: Display字体用 Orbitron（科技感），正文字体用 Inter
- **布局风格**: 卡片式三栏布局、玻璃拟态效果、流动渐变背景
- **视觉元素**: 霓虹边框、发光效果、赛博朋克美学

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 主页面 | 头部 | 渐变标题、霓虹分割线、副标题 |
| 主页面 | 输入区 | 深色文本框、行数统计、生成按钮 |
| 主页面 | 结果区 | 三张风格卡片、差异化配色、星级评价 |
| 主页面 | 批量区 | 文件拖拽区、上传进度条、下载按钮 |

### 4.3 响应性
- 桌面端：三卡片并排布局
- 平板端：两卡片布局
- 移动端：单卡片垂直布局
- 所有交互元素优化触控体验

### 4.4 动效设计
- 页面加载：元素渐入 + 位移动画
- 生成过程：卡片骨架屏脉冲效果
- 评价交互：星星填充动画
- 悬浮效果：卡片轻微上浮 + 发光增强
