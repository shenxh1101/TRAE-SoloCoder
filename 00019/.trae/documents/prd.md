## 1. 产品概述

AI辩论陪练是一款互动式辩论训练工具，用户可以选择或自定义辩题，与扮演反方立场的AI对手进行实时辩论。AI支持多种人设切换，辩论过程全程记录，结束后可生成摘要并导出为JSON文件。

- 目标用户：辩论爱好者、演讲训练者、逻辑思维提升者
- 核心价值：提供低成本、高效率的辩论对抗练习环境，通过人设切换和逻辑评分机制增强训练趣味性与针对性

## 2. 核心功能

### 2.1 用户角色

无角色区分，单用户直接使用。

### 2.2 功能模块

1. **辩论主页**：辩题选择、自定义辩题、AI人设切换、辩论对话区、评分系统、导出功能
2. **辩论记录页**：辩论历史摘要查看、JSON导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 辩论主页 | 辩题选择区 | 预设辩题列表（5-8个热门辩题），支持自定义输入辩题，选择后AI自动持反方立场 |
| 辩论主页 | AI人设切换 | 三种人设：毒舌型（讽刺挖苦）、学究型（引经据典）、热血型（激情澎湃），实时切换，影响回应语气用词 |
| 辩论主页 | 辩论对话区 | 聊天气泡式对话界面，AI先开篇阐述论点，用户输入反驳，AI持续回应，支持滚动浏览历史 |
| 辩论主页 | 逻辑评分 | 每次AI回应后出现1-5星评分组件，评分影响后续AI生成策略中句式模板的倾向 |
| 辩论主页 | 辩论控制 | 开始/暂停/结束辩论，结束时生成辩论摘要 |
| 辩论主页 | 导出功能 | 将完整辩论记录导出为JSON格式文件 |
| 辩论记录页 | 历史摘要 | 显示本轮辩论的完整摘要：辩题、双方立场、关键论点、总评分 |
| 辩论记录页 | JSON导出 | 下载包含完整对话、评分、时间戳的JSON文件 |

## 3. 核心流程

用户打开页面 → 选择/输入辩题 → 选择AI人设 → 开始辩论 → AI率先阐述反方论点 → 用户输入反驳 → AI根据用户关键词+当前人设+评分历史生成回应 → 用户对AI回应打分 → 循环辩论 → 用户点击结束 → 生成辩论摘要 → 可选导出JSON

```mermaid

    "A[打开页面]" --> "B[选择/自定义辩题]"
    "B" --> "C[选择AI人设]"
    "C" --> "D[开始辩论]"

    "F" --> "G[AI生成新回应]"
    "G" --> "H[用户对回应打分]"
    "H" --> "I{继续辩论？}"
    "I" --> "是" --> "F"
    "I" --> "否" --> "J[生成辩论摘要]"
    "J" --> "K[可选：导出JSON]"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深墨黑 (#0D0D0D) + 鲜红强调色 (#E63946)，模拟辩论的对抗张力
- 次要色：暖灰 (#2A2A2A) 作为卡片背景，金铜色 (#D4A574) 作为评分高亮
- 按钮风格：圆角微凸，带微妙阴影，强调色按钮有按压反馈
- 字体：标题使用 Noto Serif SC（宋体感），正文使用 Noto Sans SC
- 布局：左侧辩题+控制面板，右侧对话区，顶部人设切换条
- 图标风格：线性图标，配合红黑主题
- 整体氛围：模拟辩论赛场的紧张感，深色背景+红色高亮，带有"对战"视觉隐喻

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|---------|
| 辩论主页 | 辩题选择区 | 卡片式列表，选中态红色边框，自定义输入框+确认按钮 |
| 辩论主页 | AI人设切换 | 顶部三个风格化标签按钮，选中态带发光效果，各有对应图标 |
| 辩论主页 | 辩论对话区 | 左右气泡式布局，AI消息左侧灰色气泡，用户消息右侧红色气泡，带发言者标签 |
| 辩论主页 | 逻辑评分 | 气泡下方星级组件，1-5星，hover预览，点击确认，已评分显示金色星星 |
| 辩论主页 | 辩论控制 | 底部固定栏：开始/结束按钮，输入框+发送按钮 |
| 辩论主页 | 导出功能 | 侧栏按钮，点击即下载JSON |
| 辩论记录页 | 历史摘要 | 居中卡片式摘要，分段显示辩题/论点/评分，底部导出按钮 |

### 4.3 响应式

- 桌面优先设计，左右分栏布局
- 平板：左侧面板折叠为顶部抽屉
- 移动端：单列布局，对话区全屏，面板切换为底部弹出
