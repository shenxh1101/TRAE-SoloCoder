## 1. 产品概述

多人实时投票/问答互动系统是一个纯前端实时互动平台，支持主持人创建房间、发起投票与问答，参与者实时响应，结果即时可视化展示。无需后端服务器，基于 BroadcastChannel 实现同浏览器多标签页间的实时通信。

- 目标用户：课堂教学、会议互动、团队决策等场景中的主持人与参与者
- 核心价值：零部署门槛、即开即用、实时反馈、丰富可视化

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 主持人 | 创建房间自动成为主持人 | 创建房间、发起投票/问答、查看实时结果、踢人、锁定投票、导出数据、重置房间 |
| 参与者 | 输入房间码+昵称加入 | 提交投票、回答问题、抢答 |

### 2.2 功能模块

1. **大厅页面**：角色选择（创建房间 / 加入房间）、房间码输入、昵称输入
2. **主持人控制台**：发起投票、发起问答、抢答模式、实时结果面板、参与者管理、房间控制
3. **参与者面板**：实时接收投票/问答、提交回答、抢答按钮、查看结果

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 大厅页面 | 角色选择 | 选择"创建房间"或"加入房间"，创建时自动生成6位房间码 |
| 大厅页面 | 加入房间 | 输入房间码和昵称加入已有房间 |
| 主持人控制台 | 投票发起 | 选择单选/多选、自定义选项、设定倒计时（可选） |
| 主持人控制台 | 问答发起 | 发布开放式问题，参与者自由输入回答 |
| 主持人控制台 | 抢答模式 | 主持人提问，参与者抢答，首位抢答者获得发言权 |
| 主持人控制台 | 实时结果 | 投票结果显示柱状图，问答结果显示词云 |
| 主持人控制台 | 参与者管理 | 显示参与者列表，支持踢人操作 |
| 主持人控制台 | 房间控制 | 锁定投票、清空房间重置状态、导出结果为JSON |
| 参与者面板 | 投票区 | 实时显示当前投票选项，单选/多选提交 |
| 参与者面板 | 问答区 | 实时显示开放问题，输入并提交回答 |
| 参与者面板 | 抢答区 | 显示抢答问题，点击抢答按钮 |
| 参与者面板 | 结果查看 | 倒计时结束后查看投票/问答结果 |

## 3. 核心流程

### 3.1 创建房间与加入流程
主持人点击"创建房间"→ 系统生成6位房间码 → 主持人进入控制台 → 参与者输入房间码和昵称 → 加入成功进入参与者面板

### 3.2 投票流程
主持人发起投票（设定类型、选项、倒计时）→ 参与者实时收到投票 → 参与者选择并提交 → 主持人端实时聚合结果 → 倒计时结束自动公布结果

### 3.3 抢答流程
主持人发起抢答问题 → 参与者看到问题 → 第一个点击抢答的参与者获得发言权 → 其他参与者看到抢答结果

    "参与者提交回答" --> "主持人实时聚合结果"

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深靛蓝 (#1a1a2e) 搭配电光紫 (#7c3aed) 和霓虹绿 (#10b981) 作为强调色
- 按钮风格：圆角胶囊按钮，带微光晕效果
- 字体：使用 "Outfit" 作为显示字体，"Noto Sans SC" 作为中文正文字体
- 布局风格：卡片式布局，深色主题，毛玻璃效果面板
- 图标风格：线条型图标搭配微动画

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 大厅页面 | 角色选择 | 居中大卡片、深色渐变背景、房间码高亮显示、入场动画 |
| 主持人控制台 | 左侧导航 | 竖向图标导航栏、当前功能高亮 |
| 主持人控制台 | 投票配置 | 表单卡片、选项动态添加、倒计时滑块 |
| 主持人控制台 | 结果面板 | 柱状图动画、词云动画、实时更新过渡效果 |
| 主持人控制台 | 参与者列表 | 头像列表、踢人按钮hover显示 |
| 参与者面板 | 投票/问答区 | 中央大卡片、选项hover发光、提交按钮脉冲动画 |
| 参与者面板 | 抢答按钮 | 大圆形脉冲按钮、倒计时环形进度条 |

### 4.3 响应式设计
- 桌面优先设计，主持人控制台利用宽屏分栏布局
- 参与者面板适配移动端，确保课堂场景下手机可用
- 触摸优化：抢答按钮大面积点击区域

### 4.4 动画与交互
- 页面切换使用淡入淡出过渡
- 投票结果柱状图从底部生长动画
- 词云文字逐步浮现动画
- 抢答按钮脉冲波纹效果
- 参与者加入时列表项滑入动画
- 倒计时进度条平滑递减
