🔌 API 接口文档

  • GET /api/customers - 获取客户列表
  • POST /api/upload - 上传并解析财务报表
  • GET /api/uploads - 获取上传记录列表
  • GET /api/uploads/{id} - 获取上传记录详情
  • GET /api/health - 健康检查

📝 上传接口说明

  • 请求方式: POST multipart/form-data
  • 请求参数: file (文件), customer_id (客户ID), report_period (报表周期), uploader (上传人)
  • 返回格式: JSON

📊 自动提取的财务指标

  • 资产负债率 = 总负债 / 总资产
  • 流动比率 = 流动资产 / 流动负债
  • 速动比率 = (流动资产 - 存货) / 流动负债
  • 现金流比率 = 经营活动现金流 / 流动负债
  • 财务健康评分 (0-100分)
