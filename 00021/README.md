# 🎵 本地音乐播放列表管理器

一个基于Python的命令行本地音乐播放列表管理器，带有智能推荐功能。

## 功能特性

### 📋 播放列表管理
- 创建多个播放列表
- 切换和删除播放列表
- 数据持久化存储（自动保存到用户目录）

### 🎵 歌曲管理
- 添加单个MP3音乐文件
- 从文件夹批量添加音乐
- 为歌曲标记流派标签（如"摇滚"、"流行"）
- 为歌曲标记心情标签（如"快乐"、"悲伤"）
- 为歌曲评分（1-5星）
- 编辑歌曲信息
- 删除歌曲

### 🎮 播放功能
- 调用系统默认播放器播放音乐
- 顺序播放模式
- 随机播放模式
- 交互式选择歌曲播放

### 🤖 智能推荐
- 基于选定歌曲推荐相似歌曲（3首）
- 推荐算法：标签相似度（60%权重）+ 评分（40%权重）
- 支持按指定标签（流派/心情）推荐

### 📊 统计功能
- 显示每种流派的歌曲数量
- 显示每种心情的歌曲数量
- 显示评分分布
- 终端柱状图可视化展示

### 📁 导入导出
- 导出播放列表为M3U文件
- 从M3U文件导入播放列表

## 安装和运行

### 直接运行（无需依赖）
```bash
python3 music_manager.py
```

### 可选依赖（用于提取MP3元数据）
```bash
pip install -r requirements.txt
```

## 使用说明

### 主菜单
1. **创建新播放列表** - 创建一个新的播放列表
2. **切换播放列表** - 在多个播放列表之间切换
3. **删除播放列表** - 删除选中的播放列表
4. **显示所有播放列表** - 显示所有已创建的播放列表
5. **添加音乐文件** - 添加单个MP3文件到当前播放列表
6. **从文件夹批量添加音乐** - 递归添加文件夹中的所有MP3文件
7. **移除歌曲** - 从当前播放列表删除歌曲
8. **编辑歌曲信息** - 修改歌曲的流派、心情、评分
9. **显示当前播放列表歌曲** - 显示当前播放列表的所有歌曲
10. **播放歌曲** - 交互式选择并播放歌曲
11. **播放整个播放列表** - 播放整个播放列表
12. **下一首** - 播放下一首歌曲
13. **切换播放模式** - 在顺序/随机播放模式间切换
14. **智能推荐** - 基于选定歌曲推荐3首相似歌曲
15. **按标签推荐** - 按指定流派/心情推荐歌曲
16. **导出M3U** - 将当前播放列表导出为M3U文件
17. **导入M3U** - 从M3U文件导入歌曲
18. **显示统计信息** - 显示流派、心情、评分的统计图表
0. **退出** - 退出程序

## 数据存储位置

程序数据存储在用户目录下的 `.music_manager` 文件夹中：
- `~/.music_manager/config.json` - 配置文件
- `~/.music_manager/playlists/` - 播放列表数据目录

## 推荐算法说明

推荐系统采用加权评分机制：
- **标签相似度（60%）**：基于 Jaccard 相似度计算标签交集
- **评分权重（40%）**：高评分歌曲优先推荐

## 文件结构

```
.
├── music_manager.py    # 主程序入口
├── models.py           # 数据模型（Song, Playlist）
├── config_manager.py   # 配置和持久化管理
├── recommender.py      # 智能推荐引擎
├── utils.py            # 工具模块（播放器、M3U、统计）
├── requirements.txt    # 可选依赖
└── README.md           # 说明文档
```

## 注意事项

1. 播放功能会调用系统默认的音乐播放器
2. MP3元数据提取需要安装 `mutagen` 库
3. 所有数据会自动保存，无需手动保存
