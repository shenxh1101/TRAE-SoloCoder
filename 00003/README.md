# 📊 股票对比分析工具

一个功能强大的Python脚本，支持两只股票的自动对比分析，包含涨跌幅对比、PE分位点计算、AI锐评、ASCII走势图、HTML报告等功能。

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 📈 **涨跌幅对比** | 支持自定义周期（3天、5天、7天等） |
| 💹 **PE分位点计算** | 基于历史价格分布模拟计算，提供估值水平判断 |
| 📉 **ASCII走势图** | 终端纯文本可视化，无需任何图形依赖 |
| 🤖 **AI锐评** | 支持本地Ollama或在线OpenAI兼容API |
| 📄 **HTML报告** | 纯Canvas绘制图表，完全离线可用 |
| 💾 **JSON历史记录** | 所有对比自动存档，支持复盘查询 |
| 📁 **本地CSV数据** | 用户可自行准备股票数据文件 |

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 准备数据

将股票CSV数据放入 `data/` 目录，文件名格式：`股票代码.csv`

**CSV格式要求：**
```csv
date,close,high,low,volume
2024-01-01,100.0,105.0,98.0,1000000
2024-01-02,102.5,106.0,101.0,1200000
...
```

**字段说明：**
- `date`: 交易日期 (YYYY-MM-DD)
- `close`: 收盘价
- `high`: 最高价
- `low`: 最低价
- `volume`: 成交量

### 3. 基础使用

```bash
# 对比两只股票（默认7天）
python main.py compare 600519 000858

# 指定3天周期
python main.py compare 600519 000858 --period 3

# 不生成HTML报告
python main.py compare 600519 000858 --no-html

# 不保存历史记录
python main.py compare 600519 000858 --no-history
```

### 4. 其他命令

```bash
# 查看历史记录
python main.py history
python main.py history --limit 20

# 查看某对股票的对比趋势
python main.py trend 600519 000858

# 列出可用股票
python main.py list

# 查看AI配置
python main.py ai-config

# 清除历史记录
python main.py clear

# 查看帮助
python main.py --help
```

## 🤖 AI锐评配置

本工具支持三种AI模式，通过环境变量配置。

### 方式一：本地 Ollama（推荐，完全免费）

#### 1. 安装 Ollama

**macOS:**
```bash
# 使用 Homebrew
brew install ollama

# 或从官网下载：https://ollama.ai/
```

**Linux:**
```bash
curl -fsSL https://ollama.ai/install.sh | sh
```

**Windows:**
从官网下载安装包：https://ollama.ai/

#### 2. 启动 Ollama 服务

```bash
# 启动服务
ollama serve

# 或后台运行
ollama serve &
```

#### 3. 下载模型

推荐使用中文效果较好的模型：

```bash
# 通义千问2（推荐，中文效果好）
ollama pull qwen2:7b

# 或更小的版本
ollama pull qwen2:1.5b

# Llama 3（英文好，中文一般）
ollama pull llama3:8b

# Mistral（速度快）
ollama pull mistral:7b

# 查看已安装模型
ollama list
```

#### 4. 运行程序

```bash
# 使用默认配置
python main.py compare 600519 000858

# 或指定模型
STOCK_AI_MODEL=qwen2:7b python main.py compare 600519 000858
```

### 方式二：OpenAI 兼容 API

```bash
# 配置环境变量
export STOCK_AI_API_TYPE=openai
export STOCK_AI_API_BASE=https://api.openai.com/v1
export STOCK_AI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxx
export STOCK_AI_MODEL=gpt-3.5-turbo

# 运行
python main.py compare 600519 000858
```

### 方式三：其他兼容 API（如 DeepSeek、阿里百炼、腾讯混元等）

```bash
# 示例：DeepSeek
export STOCK_AI_API_TYPE=compatible
export STOCK_AI_API_BASE=https://api.deepseek.com/v1
export STOCK_AI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxx
export STOCK_AI_MODEL=deepseek-chat

# 运行
python main.py compare 600519 000858
```

### 方式四：强制使用模板模式（无需网络）

```bash
STOCK_AI_API_TYPE=template python main.py compare 600519 000858
```

### 配置文件

复制 `.env.example` 为 `.env` 并修改配置：

```bash
cp .env.example .env
```

`.env` 内容：
```dotenv
# API类型: ollama | openai | compatible | template
STOCK_AI_API_TYPE=ollama

# API地址
STOCK_AI_API_BASE=http://localhost:11434

# API密钥（OpenAI兼容API需要）
STOCK_AI_API_KEY=your_api_key_here

# 模型名称
STOCK_AI_MODEL=qwen2:7b

# 请求超时时间(秒)
STOCK_AI_TIMEOUT=30

# 最大重试次数
STOCK_AI_MAX_RETRIES=2

# 重试间隔(秒)
STOCK_AI_RETRY_DELAY=2

# API调用失败时是否降级到模板模式 (true/false)
STOCK_AI_FALLBACK=true
```

### 查看当前配置

```bash
python main.py ai-config
```

## 🔧 错误处理与容错

本工具具备完善的容错机制：

| 错误类型 | 处理方式 |
|----------|----------|
| HTTP 4xx错误 | 显示具体错误信息（如认证失败、地址不存在） |
| HTTP 5xx错误 | 自动重试2次（可配置），失败后降级 |
| 连接超时 | 自动重试2次（可配置），失败后降级 |
| 连接被拒绝 | 自动重试，提示检查服务是否启动 |
| 响应不是JSON | 提示解析失败，降级到模板 |
| 响应缺少字段 | 自动填充模板内容 |
| 响应内容为空 | 降级到模板 |
| 未知错误 | 捕获所有异常，降级到模板 |

## 📄 HTML 报告说明

每次对比会自动生成HTML报告，保存在 `output/reports/` 目录。

**特点：**
- 完全离线可用，无任何外部CDN依赖
- 纯Canvas绘制图表，响应式布局
- 包含涨跌幅对比、PE分位点、走势曲线等图表
- 支持手机端查看
- 深色ASCII走势图展示

## 💾 历史记录

所有对比结果自动保存到 `output/history.json`，包含：
- 对比时间
- 股票代码
- 周期天数
- 涨跌幅、PE分位点等核心数据
- AI综合评价
- HTML报告路径

## 🎯 常见问题

### Q: Ollama 启动失败怎么办？
A: 检查端口是否被占用，默认端口是11434。可以用 `lsof -i :11434` 检查。

### Q: 模型下载太慢？
A: 可以使用国内镜像，或选择更小的模型如 `qwen2:1.5b`。

### Q: 如何自定义AI提示词？
A: 修改 `ai_commentator.py` 中的 `_build_prompt` 方法。

### Q: PE分位点是真实计算的吗？
A: 是基于历史价格的模拟计算，仅供参考。如需真实PE数据，请在CSV中添加pe字段并修改代码。

### Q: 可以添加更多技术指标吗？
A: 可以在 `analysis.py` 中添加MACD、KDJ等指标的计算逻辑。
